# Nigeria Food Price Intelligence Tracker

## Overview

An end-to-end data analytics project tracking food prices across Nigeria using Python, SQL Server, and Power BI. The project explores food price trends, regional differences, changes in food basket costs, and potential relationships between food prices and exchange-rate movements.

## Objectives

* Analyse food price changes over time.
* Compare prices across Nigerian states and markets.
* Track changes in the cost of a selected food basket.
* Investigate relationships between food prices and exchange-rate movements.
* Build an interactive Power BI dashboard and automated reports.

## Tools

* **Python:** Data processing and analysis
* **SQL Server:** Data storage and querying
* **Power BI:** Interactive dashboards
* **DevExpress Reports:** PDF reporting

## Project Status

Currently in the data auditing stage. Further analysis, database development, visualisation, and reporting will follow.

## Data Source

World Bank — Nigeria High Frequency Crowdsourced Prices (HFCP).
